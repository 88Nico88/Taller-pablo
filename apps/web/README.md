# Web administrativa minima

Interfaz estatica para operar el primer flujo MVP contra el backend local.

## Uso

1. Levantar el backend:

```bash
cd ../../services/api
npm run dev
```

2. Abrir `index.html` en el navegador.
3. Presionar `Entrar demo`.

## Funciones disponibles

- Login demo.
- Dashboard basico.
- Crear cliente.
- Crear vehiculo.
- Crear orden.
- Crear repuesto.
- Consumir repuesto desde orden.
- Buscar historial por patente.

## Limitaciones

Es una primera interfaz operativa. No reemplaza todavia una app productiva con permisos finos, persistencia real, carga de fotos ni offline.
