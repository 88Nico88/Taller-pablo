Este proyecto es un sistema de gestion para talleres automotrices. La idea es que cada vehiculo tenga una ficha completa por patente, donde se vea el cliente, el historial, las ordenes de trabajo, las inspecciones, los repuestos utilizados, fotos y presupuestos. El valor principal es ordenar la operacion diaria del taller: recepcion sabe que autos estan dentro, el mecanico puede actualizar desde el celular junto al vehiculo, y el dueno puede ver estados, stock y trabajos pendientes sin depender de papel, WhatsApp o memoria del personal.

La primera version no intenta hacer todo de una vez. Se enfoca en el flujo mas importante: registrar cliente, asociar vehiculo, crear orden, inspeccionar, presupuestar, descontar repuestos, cerrar el trabajo y luego recuperar toda la historia buscando la patente. Despues se pueden sumar agenda, WhatsApp, facturacion, portal del cliente y reportes avanzados.
